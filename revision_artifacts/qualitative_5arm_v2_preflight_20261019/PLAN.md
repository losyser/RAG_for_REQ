## Design and exact comparison

Five groups, each 60 original requirements: semantic-old, semantic-new-[Q], random-old, random-new-[Q], noRAG-original. Total 300 Stage4 generation attempts, one per source/group, no repeats or retries. All use DeepSeek Flash, temperature=0, max_tokens=8192, JSON response and thinking disabled in one execution window. The noRAG template is the original saved template, including permission to use engineering knowledge and empty citations; no Q instruction is added to it.

120 saved contexts are reused unchanged from v1, tied to 60 source requirements and the frozen KB hash. Saved context availability is 60/60 for each retrieval arm, but semantic nonempty evidence is only 58/60: OR035 and OR058 remain empty; random is 60/60 nonempty. An empty semantic context must remain TBD, never receive invented [Q] support. The same source can have different semantic and random evidence: strict input identity applies ONLY to old/new within the same retrieval arm. The noRAG generation constraint differs, so its comparison is workflow-level, not a pure retrieval causal effect.

The new prompt adds only the third category and changes two to three in the category heading. [Q] must begin the criterion, have valid citations and applicable-condition text, be testable, and quote or faithfully paraphrase identifiable evidence. New inference or synthesis is forbidden. Unknown model/condition remains unknown, never fabricated as applicability. Existing fields retain historical wording to keep the intervention minimal. Identical historical evidence selection is numeric-first, max12 units, first500 characters each; no latest production risk/quarantine/unit fixes are mixed into either arm.

Historical byte-for-byte reproducibility remains unproven: original set ordering, runtime environment overrides, complete provider requests and immutable historical model identity were not all archived. Saved mapping order now fixes the new comparison. The old template is extracted from the pre-2026-10-17 snapshot; current experiment parameters are explicitly frozen, not claimed identical to every past refill. The Stage4 label here refers to generation, distinct from any older script comments naming grading Stage4.

## Pre-frozen output and evaluation rules

The isolated classifier_v2.py is version q-format-v2-20261019, not a production replacement. Unit tests cover placeholders, missing/invalid/out-of-context citations, mixed Q/TBD, unknown conditions and semantically bad text that nevertheless passes structural format. It never writes old grades or promotes Q to legacy A/B.

Request outcomes: success, transport failure, refusal, truncation, invalid JSON/schema. All planned attempts remain in denominators; all raw outputs retained. Row candidates: [Q] candidate, TBD/mixed candidate, numeric candidate, unmarked nonnumeric candidate, missing/invalid. Lexical categories are candidates, not truth labels. A misplaced [Q] or bad reference remains in the all-Q review population as format-fail, not silently dropped. Distinct valid rows are counted by response slot/row position, not deduplicated to improve results.

Q format pass requires prefix, nonempty body, no mixed TBD, nonempty applicable_condition, and all citations valid in frozen KB AND actual supplied context. Unknown condition text can pass format but remains applicability unknown. Verifiability and fidelity are semantic checks, not asserted by format. An unmarked qualitative sentence is not Q-format pass; numeric-looking criterion is not automatic numeric correctness.

Semantic support is independently direct/partial/contradicted/insufficient/uncertain/not_assessed; applicability is explicit_match/explicit_mismatch/unknown/general_rule_with_basis. Direct textual support and target applicability are reported separately; only the joint confirmed case may be called directly usable for that target. Same number, valid ID or authoritative tier does not establish semantic support. Source reliability and edition identity are another independent field. Full conditions outside a truncated excerpt remain unknown.

Freeze request-level and source-level paired summaries, row-type counts, Q-format-pass proportion, Qwen assessed denominator and failures, support and applicability distributions, and the joint direct+applicable proportion. Show planned/returned/parseable/reviewed denominators. Legacy numeric A/B remains separate and unchanged. No automatic claim of engineering correctness, completeness, or superiority from higher Q counts.
