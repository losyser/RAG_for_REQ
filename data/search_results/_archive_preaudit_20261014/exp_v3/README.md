# exp_v3 Data Files — Source Mapping to Paper Tables

This directory contains output files from the v3 experiment pipeline.
Not all files use identical counting definitions; this README identifies
which file corresponds to each paper table and explains discrepancies.

## Authoritative files (used directly in the paper)

| Paper table | Authoritative file | Description |
|---|---|---|
| Table 5 (post-hoc KB numeric verification) | `norag_kb_verification_summary.txt` | Physical-unit regex extraction: 117 RAG / 79 no-RAG numeric shalls |
| Table 9 (blind pairwise evaluation) | generated by swap-debiased blind eval script (see `scripts/eval/blind_eval_swap.py`) | Overall 14/118/108 (RAG wins / ties / no-RAG wins) |
| Table 4 (H_hard) | `eval_v3_summary.txt` — H_hard section only | RAG mean 0.0046, no-RAG mean 0.0019 |

## Legacy / alternative-methodology files

### `eval_v3_summary.txt`
- **Numeric rates (32.9% RAG / 49.2% no-RAG)**: uses a broad token-level
  digit count, not the physical-unit extraction regex used for post-hoc
  verification. These differ from the paper's 24.2%/32.4% by design.
- **Blind eval section (32/142/66)**: single-pass run *without* left-right
  swap debiasing. The paper uses the swap-debiased results (14/118/108),
  where each pair is evaluated twice with arm positions exchanged and a
  dimension is counted as a win only if both passes agree.

### `traceability_summary.txt`
- Reports 118 RAG / 86 no-RAG numeric shalls (24.4% / 35.2%) using a
  slightly different regex (includes numbers not followed by a standard
  physical unit token). The paper uses 117/79 from the stricter
  physical-unit regex in the post-hoc verification script.

## Summary

The paper's reported numbers are internally consistent and sourced from
`norag_kb_verification_summary.txt` (Table 5) and the swap-debiased blind
eval run (Table 9). The `eval_v3_summary.txt` and `traceability_summary.txt`
files reflect earlier or alternative counting methods and are retained for
reproducibility audit purposes.
