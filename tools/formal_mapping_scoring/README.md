# 正式固定子集评分（协调者工具）

本目录是独立评分工具。server.py仅提供本地验证函数，不启动服务；不替换正在使用的网页，不读写其local_records。输入文件只读，输出必须为不存在的新路径。不修改已交付模板或冻结协议。

运行：Python -I score_formal_review.py --package 正式assignment.json --manifest FROZEN_SAMPLE.json --predictions e1_predictions.json --records 专家A.xlsx [专家B.xlsx或网页备份.json] --expected-reviewers 1或2 --output 新的结果.json

支持正式xlsx、完整网页JSON备份或转换器readback JSON。Python环境需openpyxl。冻结预测SHA256必须匹配manifest。命令行严格拒绝重复JSON键，避免重复源ID被解析器静默覆盖；Excel按稳定源ID/配对ID验证，不按得分选择样本。

主结果仅在固定8源全部判定、完整目录查漏确认、无未决不确定/疑问、首判/候选暴露与计时记录齐备时产生。预期两位评审时不能回退为单评审；两人最终参考配对不同即阻断，工具不擅自裁决。结构损坏或版本/哈希错误直接报错退出；语义不完整返回status=blocked、scores=null及逐项原因。不会删除未完成源或将未知当负例。

主统计micro precision/recall/F1汇总全部8源配对，补漏阳性进入gold及FN分母。附全部源的计数与macro F1。零分母保留null；不静默忽略macro中的未定义源。输出覆盖率、审查状态、首判/补漏记录、候选暴露声明、方法版本来源及输入哈希。覆盖率是处理状态，不证明gold正确。单人不报告双人一致性，双人也不把集合一致冒称kappa。

保留限制：候选池会提示最终判断；Excel首判顺序和暴露时间为自报，不能声称强盲法。旧网页记录可能没有计时/暴露字段：将如实阻断，不补造、不改写原记录；后续可另行核实缺少的流程证据，本工具不要求重填已完成答案，也不提供自动补证。未解决的首判池外配对需要真实结论；保留原答案，不能直接删去。争议裁决记录适配不在本工具中。

固定样本仅是剩余58源的8源预算受限补充评审，不代表75个独立样本、不证明统计充分、不外推60源或其他系统。DeepSeek现存预测匹配v3历史Stage1且被v4复用；不是新跑v4。其他三方法来自同一冻结预测文件。

验证使用25项纯合成单元测试、6项正式模板隔离副本/只读检查，以及17项已有回归，共48项。安装后独立目录31项再次通过。所有人工判定值仅存在内存或自动清理的临时合成副本。没有对真人记录评分，没有产生研究F1。
