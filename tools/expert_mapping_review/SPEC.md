# 中文本地独立专家审核工具

本工具只实现 S2 映射审核，不重跑实验、不调用模型、不改论文或回复稿。样本量及正式抽样协议尚未确认，不能自行生成正式样本或答案。

## 用户要求与验收边界

- 新建审查、保存、打开旧审查按钮；每位专家独立任务。
- 关闭和服务重启后恢复，自动保存，未保存保护，重复请求不创建重复任务。
- 中文原始需求、中文备注和稳定 ID、数据版本保存；后续英文转换不覆盖原记录。
- 一条源需求为完整审核单位：独立首判、候选相关/不相关/不确定/未答、完整 taxonomy 查漏。
- 隐藏模型身份、AI 预判和其他专家答案；不向网页发送 PRIVATE 文件、现有 expert_key 或模型预测文件。
- 仅绑定 127.0.0.1，不部署。保存采用校验、原子替换、上一版备份及版本冲突保护。
- 工具验证仅用内置隔离练习；实际浏览器验证新建两任务隔离、保存重启、补漏导出、取消/重复点击和损坏文件保护，保存截图和报告。
- 桌面快捷入口，避免历史 Python 环境变量污染。

## 数据与版本边界

正式包由协调者在抽样方案确认后，显式给出源需求 ID 与协议编号生成；四方法共用相同包。工具不抽样、不选高分源、不计算 P/R/F1。
任务包只读取现有 e1_pool.csv 与 evidence_taxonomy.py 的静态常量，保留源数据 SHA256；不执行 taxonomy 文件。保存的 Stage 1 预测对应较早版本，不能当作冻结 v4/513 输出实验性能。
一至两位专家、各一至两小时只用于规划预算，不决定固定样本量。S1/S3/S4 不在此工具范围。
